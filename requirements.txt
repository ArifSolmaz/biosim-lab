# Dependencies for the hosted Streamlit app.
# Streamlit Community Cloud installs this file automatically, together with the
# system libraries listed in packages.txt.
#
# This is the FULL set of everything that genuinely works on a managed host.
# Verified by installing it in a linux/amd64 Debian bookworm container — the
# same platform Streamlit Cloud runs — and importing, meshing, rendering and
# running the whole test suite there.
#
# Three optional components are deliberately absent because installing them
# would not help; the app's Environment page explains each:
#
#   napari              needs Qt and a display server. It would install, report
#                       itself present, and still be unable to open a viewer.
#   openfoam, elmer     external binaries, not Python packages. They come from
#                       apt repositories a managed host does not carry.
#   cellpose, stardist  installable, but they pull a deep-learning runtime. The
#                       default PyTorch wheel bundles CUDA at roughly 2.5 GB,
#                       which will not fit a free tier. See the bottom of this
#                       file for the CPU-only opt-in.
#
# For a full local install use:  pip install -e ".[mesh,imaging]"
